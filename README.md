# Tailwind CSS Newsletter Component

A responsive, production-ready newsletter subscription UI card built entirely with semantic HTML5 and the Tailwind CSS utility-first framework. 

**Live Deployment:** https://gsreecharan.github.io/newsletter-tailwind-component/

---

## Overview

This project demonstrates the implementation of a modern, responsive UI component utilizing Tailwind CSS. It focuses on utility-class architecture to style elements directly within the markup, avoiding custom CSS files where possible.

### Key Features
- **Utility-First Styling:** Rapid UI development using Tailwind's core utility classes for flexbox, spacing, typography, and colors.
- **Responsive Design:** Adapts fluidly to mobile, tablet, and desktop viewports using maximum width constraints and auto margins.
- **Modern UI Patterns:** Features linear background gradients, customized input focus rings (`focus:ring-blue-500`), and smooth hover state transitions.
- **Form UI:** Includes a styled email input field with custom placeholder sizing and a fully styled call-to-action submit button.

---

## Technical Stack

- **Markup:** HTML5
- **Styling:** Tailwind CSS (v3.x)
- **Build Tools:** Node.js / npm (for Tailwind CLI)
- **Deployment:** GitHub Pages
